# ホスト名・パス割り当て台帳

共有 Ingress が受け付けるホスト名と、パスプレフィックスごとの転送先を管理する。
サービスの追加・削除時は本台帳と Ansible の変数を同時に更新する。

## 割り当てルール

- 全サービスは単一のホスト名配下に、サービスごとのパスプレフィックスを割り当てて公開する
- パスプレフィックスは、他のサービスと重複させない
- 基盤はパスプレフィックスを除去してバックエンドへ転送する
- 転送先の Service は、共有 Namespace に配置する
